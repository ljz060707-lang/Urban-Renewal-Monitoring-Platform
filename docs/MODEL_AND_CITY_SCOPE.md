# 亚米遥感系统的模型与城市应用

本项目是面向多城市的亚米级遥感建筑制图与城市更新监测系统。西安、北京南站、深圳等是应用或验证地点。西安的日期、底图、人工参考、处理参数、区域结果和实测指标用来描述对应批次。模型在某个城市训练、校准或验证的结论，以对应数据和评价范围为准。跨城市迁移需要验证当地影像条件和目标语义。

| 环节 | 通用职责 | 城市应用需要绑定 |
|---|---|---|
| 影像与格网 | 组装影像、坐标、拍摄日期、可观测范围 | AOI、影像、实际日期台账、格网 |
| 建筑识别 | 提取可见屋顶、建筑实例和独立补检 | 模型版本、影像条件、当地候选阈值 |
| 外立面治理 | 标注立面风险，按权限执行筛选或剔除 | 影像视角、判决策略、当地质量验证 |
| 位移与配准 | 估计地面配准和逐栋屋顶到轮廓的位移 | 坐标、控制证据和位移场适用范围 |
| 分栋与轮廓 | 拆分粘连候选、保留可信边界和实例身份 | 适用建筑类型及误拆、漏拆评价 |
| 时序身份追踪 | 按实际相邻期匹配同栋，记录冲突与不确定性 | 各期影像、候选及城市观测日期 |
| 变化与地表状态 | 汇总存在、缺失与变化证据，记录未知及审阅状态 | 独立事件证据、可观测性和本地校验 |
| 面积与交付 | 生成栅格、矢量、并集面积分数和可追溯回执 | 格网、投影、面积口径和正式资格 |

## 存放规则

1. 城市应用采用 02_城市成果/地点/地点YYYY-MMDD/01_输入 和 02_产出。批次日期记实际产出时间，影像实拍日期另写在清单。日期证据还未查清的批次归入待核。共用底图和参考从 03_城市输入影像与参考绑定，城市批次的输入入口链接到它们。
2. 权重、训练曲线、模型参数、校准和训练验证保存在 05_训练记录与模型/按模块管理/模块/版本。目录按模块职责命名。带西安地名的版本标明在西安开发或适配，通用能力仍须验证。城市产出记录实际调用的模型版本与哈希。
3. 04_训练集与标注存放公共训练资料及依法可用的本地监督资料。训练、内选、独立验收与按参考拟合分别记录。
4. 06_验收与审阅保存系统归档、通用验收和审阅资料。11 月 23 日档案包含系统整理报告和应用迁移记录。它们的时间记录是整理日期。
5. 旧路径通过联接或兼容硬链接保留。新运行优先记录模块目录和城市批次的规范路径。城市结果直接改名或重写历史冻结清单前，先核查引用。
