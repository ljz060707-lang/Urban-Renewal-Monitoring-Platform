# 工具目录

根目录保留有路径依赖的命令。工具按工作目的在[文件索引](../docs/CODE_INDEX.md#tools)归类，覆盖单期识别与重放、空间对齐、身份匹配、训练与验证、GIS 图表、验收及运维。新实验在 research 对应模块下建目录，跨模块可复用算法放入 src。

- [run_xian_r5_integration.py](run_xian_r5_integration.py) 是西安应用入口。
- [maintenance](maintenance/) 存放仓库维护工具。
- [urrs_lite_review](urrs_lite_review/) 存放轻量审阅工具。
- 项目历史中的一批西安案例脚本已从本目录归入 [research/historical_xian_reviews](../research/historical_xian_reviews/)。
